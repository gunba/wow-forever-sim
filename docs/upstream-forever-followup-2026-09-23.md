# WoWSims Forever follow-up — 23 September 2026

Compared [`08dfb6be`…`9e7fd623`](https://github.com/wowsims/forever/compare/08dfb6be22a0...9e7fd62313cb), 225 additional commits, with the published simulator at [`7fe1b536`](https://github.com/gunba/wow-forever-sim/commit/7fe1b5366). Most of this range builds a client-spell-data store and moves class code to its accessors; it does not supply 225 observed changes to combat rules. The current branch still has unimplemented class bodies, including [Aspect of the Hawk](https://github.com/wowsims/forever/blob/9e7fd623/sim/hunter/aspects.go), so its generated rows cannot be substituted wholesale for working class simulations.

The [Warrior test](https://github.com/wowsims/forever/blob/9e7fd623/sim/warrior/dps/dps_test.go) still names `ui/specs/warrior/dps/gear_sets/p1_fury`, `p4_fury` and others, despite those files not being present. These references are not usable optimized level-60 Forever sets. Our source-reviewed item pool and measured gear selections remain independent of them.
