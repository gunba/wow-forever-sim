# Previous modeled-gear benchmark

These files preserve the 184-build/race release at Git revision
[`62976de00`](https://github.com/gunba/wow-forever-sim/commit/62976de00).
They include the old 184 baseline requests/results, 552 sensitivity
requests/results, chart, summary and input players.

This release still paired Grace of Air with a simulated legacy Windfury
weapon imbue on non-Shamans, allowed two removed Crusade talent points in
both Retribution builds and permitted critical Deep Wounds ticks. It is
**not** comparable with the corrected release as a pure balance-patch
effect. Use that revision's simulator to replay these inputs exactly.
