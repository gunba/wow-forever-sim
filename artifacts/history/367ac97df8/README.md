# Previous simulator release

These files preserve the 184-profile benchmark and paired tank comparisons
from [`367ac97df8`](https://github.com/gunba/wow-forever-sim/commit/367ac97df8).
The compressed baseline and sensitivities retain all 736 complete DPS
requests/results. `tanks/` retains the 24 complete tank comparisons.

They predate the [class-effects follow-up](../../../docs/upstream_elliot_review.md),
including Spirit-based Life Tap, explicit pet talents, Hunter effect masks,
Moonfury, Inner Focus, Penance cost, stronger Trueshot and Thorns.
Use the pinned engine to reproduce these historical numbers.
