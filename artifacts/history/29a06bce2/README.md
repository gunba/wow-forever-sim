# Benchmark snapshot

These files preserve the previously published results from
[`29a06bce2037b5ff4bbe945a24bed45d1b8048af`](https://github.com/gunba/wow-forever-sim/tree/29a06bce2037b5ff4bbe945a24bed45d1b8048af).
They are superseded, not the current DPS ranking.

- `forever_dps_5min.json` contains the 147 requests, input profiles and results.
- `forever_sensitivity.json` and `sensitivity/` retain the earlier scenarios,
  including the former +20% equipment comparison.
- `sensitivity/before_charge_fix.json` is an older diagnostic already present
  in that release; it is not a paired scenario for this matrix.

Use the linked code revision to reproduce these historical mechanics.
Current results and their assumptions are linked from the repository README.
